## 4. 行为验收基线（从前代 862 测试映射）

新引擎 Phase 5 验收 = 以下场景在新架构下全部可执行且行为等价
（测的是行为，不是代码）：

**生命周期**
- E2E 全回合：turn.start → 流式 → 定稿，ack 全程 consumed，一回合一卡
- 回合外 deliver：静态卡、不劫持活跃卡、cron 溯源页脚
- turn.abort / watchdog 封卡：卡收敛、后续帧 fallback
- 停机 seal_all：活跃卡全部先定稿再关闭

**竞态**
- 建卡窗口并发帧：恰一张卡（Q3 守卫回归）
- 跨 chat 并行互不干扰
- 同 chat 新 turn 打断旧 turn：旧卡 seal、新卡建立
- 长回合（模拟 >540s）：续期触发、无 200850 中断

**clarify**
- 边界窗口：finalize 后 1.2s 内 clarify.request → 同卡暂停续流
- 窗口超时：真落定
- 表单三态渲染（select / multi_select / input；answered / unauthorized）

**降级**
- 首次卡片失败 → 该帧 fallback + chat 降级
- 冷却后恢复探测成功 → 回 CHAT_OK
- 持续失败 → 每 帧 fallback（消息全走原生，零丢失）

**渲染**
- 懒面板：纯 answer 回合无空面板
- 面板分组：多轮思考分组标题、工具行合并 (×N)、耗时标签回填
- 字节预算裁剪顺序与不可裁剪项
- 页脚：全字段 / 缺字段 / 中止原因 / 重复定稿不重放
- Golden 快照全绿（03 §8）

**legacy 兼容**
- 文本转换器：前代文本编码 → 事件流的转换语义与前代分类器一致
  （工具行/思考/围栏/通知行/去重后缀）
